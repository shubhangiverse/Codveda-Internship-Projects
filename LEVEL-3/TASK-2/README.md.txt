Project Title: N-Queens Problem Solver

Description:
This project is a Python implementation of the classic N-Queens Problem. The objective is to place N queens on an N × N chessboard in such a way that no two queens can attack each other. A queen can attack horizontally, vertically, and diagonally, so the program must find positions where all queens are placed safely.

The solution uses the Backtracking Algorithm, which systematically explores possible queen placements and backtracks whenever a conflict occurs.

Tools Used:

* Python 3
* PyCharm IDE / VS Code

Features:

* Chessboard represented as a 2D array
* Backtracking algorithm implementation
* Safe position checking for queen placement
* Automatic generation of valid solutions
* Display of the final chessboard configuration
* User-defined board size (N)

Objectives:

* Understand the Backtracking Algorithm
* Learn recursive problem solving
* Work with 2D arrays in Python
* Implement constraint satisfaction techniques
* Improve logical thinking and algorithm design skills

Learning Outcomes:
Through this project, I learned how to:

* Represent a chessboard using a 2D array
* Use recursion and backtracking effectively
* Check row, column, and diagonal constraints
* Solve combinatorial optimization problems
* Develop efficient problem-solving strategies
* Visualize algorithm execution step by step
