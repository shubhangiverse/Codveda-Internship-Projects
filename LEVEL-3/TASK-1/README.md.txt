Project Title: File Encryption and Decryption

Description:
This project is a command-line File Encryption and Decryption application developed using Python. The program allows users to encrypt the contents of a text file and save the encrypted data into a new file. It also provides the functionality to decrypt encrypted files and restore the original content.

Tools Used:

* Python 3
* PyCharm IDE / VS Code

Features:

* Menu-driven interface
* File reading and writing operations
* Encryption using Caesar Cipher technique
* Decryption of encrypted files
* ASCII character manipulation using ord() and chr()
* Exception handling for missing files
* User-friendly interaction
* Separate output files for encrypted and decrypted data

Objectives:

* Learn file handling in Python
* Understand encryption and decryption concepts
* Work with text file operations
* Implement loops and conditional statements
* Use exception handling for error management
* Develop problem-solving and logical thinking skills

Learning Outcomes:
Through this project, I learned how to:

* Read from and write to text files
* Use loops and conditional statements effectively
* Apply the Caesar Cipher encryption technique
* Convert characters using ASCII values
* Handle exceptions using try-except blocks
* Build a menu-driven command-line application
