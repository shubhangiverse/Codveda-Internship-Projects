Project Title: Simple Calculator Using Python

Description:
This project is a simple command-line calculator developed using Python. It allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

Objectives:

* Learn the use of functions in Python
* Take user input and process it
* Implement conditional statements
* Handle division by zero errors
* Display results in a user-friendly format

Features:

1. Addition of two numbers
2. Subtraction of two numbers
3. Multiplication of two numbers
4. Division of two numbers
5. Error handling for division by zero
6. Clean and organized user interface

Technologies Used:

* Python 3
*PyCharm IDE 

Learning Outcomes:
Through this project, I learned how to:

* Create and use functions
* Work with user input
* Use if-elif-else statements
* Handle errors and exceptions
* Structure a Python program in a clean and organized way
