Project Title: Number Guessing Game

Description:
This project is a command-line Number Guessing Game developed using Python. The program randomly generates a number between 1 and 100, and the user attempts to guess the correct number within a limited number of attempts.

Tools Used:

* Python 3
* PyCharm IDE

Features:

* Random number generation using the random module
* User-friendly game interface
* Feedback for incorrect guesses

  * Too High
  * Too Low
* Limited number of attempts
* Success and Game Over messages
* Input validation and error handling

Objectives:

* Learn how to use Python modules
* Understand loops and conditional statements
* Work with user input
* Implement decision-making logic
* Develop problem-solving skills

Learning Outcomes:
Through this project, I learned how to:

* Use the random module in Python
* Implement loops and conditions
* Handle user input
* Control program flow using attempts
* Build an interactive command-line application
