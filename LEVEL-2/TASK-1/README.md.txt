Project Title: To-Do List Application

Description:
This project is a command-line To-Do List Application developed using Python. The application allows users to add tasks, view tasks, delete tasks, and mark tasks as completed. Task information is stored in a JSON file, ensuring that data is saved even after the program is closed.

Tools Used:

* Python 3
* PyCharm IDE
* JSON File Storage

Features:

* Add new tasks
* View all tasks
* Delete existing tasks
* Mark tasks as completed
* Store tasks permanently using JSON
* Basic error handling for invalid inputs

Objectives:

* Learn file handling in Python
* Understand JSON data storage
* Work with lists and dictionaries
* Implement loops and conditional statements
* Build an interactive command-line application

Learning Outcomes:
Through this project, I learned how to:

* Store and retrieve data using JSON files
* Use loops and conditional statements
* Work with lists and dictionaries
* Handle user input and validation
* Build a simple data management application
