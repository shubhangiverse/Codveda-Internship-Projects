Project Title: Data Scraper Using Python

Description:
This project is a simple web scraper developed using Python. The application retrieves webpage content from a website, extracts book titles using BeautifulSoup, and stores the extracted data in a CSV file.

Website Used:
https://books.toscrape.com

Tools Used:

* Python 3
* PyCharm IDE
* Requests Library
* BeautifulSoup Library
* CSV Module

Project Objectives:

* Retrieve webpage content using the Requests library
* Parse HTML content using BeautifulSoup
* Extract book title information from a webpage
* Save the extracted data into a CSV file

Features:

1. Connects to a website and downloads HTML content
2. Parses webpage data using BeautifulSoup
3. Extracts book titles from the website
4. Displays extracted titles in the console
5. Saves extracted data into a CSV file
6. Handles webpage access verification using status codes

Files Included:

* scraper.py
* books.csv
* README.txt
* Demo_Video.mp4

Learning Outcomes:
Through this project, I learned how to:

* Use the Requests library to retrieve webpage content
* Parse HTML documents using BeautifulSoup
* Extract specific information from webpages
* Store extracted data in CSV format
* Build a basic web scraping application using Python

Challenges Faced:
One challenge was understanding how webpage data is structured in HTML. By inspecting webpage elements and using BeautifulSoup methods, I was able to identify and extract the required information successfully.

Conclusion:
This project provided practical experience with web scraping concepts and demonstrated how Python can be used to collect and organize data from websites efficiently.
